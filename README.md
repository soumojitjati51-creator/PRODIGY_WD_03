# 🎮 React Tic-Tac-Toe (with Unbeatable AI)

A modern, fully responsive Tic-Tac-Toe game built with React, Vite, and Tailwind CSS. Play locally against a friend or challenge the built-in AI, featuring three difficulty levels including an unbeatable "Hard" mode powered by the Minimax algorithm.

## ✨ Features

*   🤖 **Player vs AI Mode:** Choose between Easy (random moves), Medium (blocks & wins), and Hard (unbeatable Minimax algorithm).
*   🧑‍🤝‍🧑 **Player vs Player Mode:** Classic local multiplayer.
*   🌗 **Dark / Light Theme:** Seamlessly toggle between dark and light modes using Tailwind CSS v4.
*   🏆 **Dynamic Scoreboard:** Keeps track of wins and draws separately for Human and AI modes.
*   ↩️ **Undo Functionality:** Made a mistake? Instantly revert to your previous move.
*   🎉 **Victory Confetti:** Celebratory confetti animation whenever a player wins the game.
*   📱 **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

*   **Frontend Framework:** React (with Hooks)
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS (v4)
*   **Extras:** `react-confetti`
